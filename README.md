## 技术栈

纯前端实现，零依赖、零构建：

- HTML5 / CSS3 / Vanilla JavaScript
- Canvas 2D 地球仅在加载与窗口尺寸变化时绘制，像素比例上限为 1.25
- 地球漂移、三层轨道光点、星空闪烁、芯片扫描与虚拟形象呼吸使用 CSS 动效；离开首屏或切换标签页后暂停
- 星空最多 38 个星点，手机端降为 16 个；无粒子模拟循环
- 首屏虚拟形象支持拖拽 / 方向键旋转 360°，点击切换微笑表情
- 支持减少动态效果；入场动效只播放一次，项目图片延迟加载
- 展示字体本地自托管（Anton / Instrument Serif），无外部字体请求；无框架、无 CDN
